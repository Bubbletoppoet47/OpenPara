OpenPara for Windows

Installs for your user only, with its own Python and every package it needs. Adds a Start-menu entry.

Latest version: see the releases page.
Download the installer

Install in three steps

  1. Download and run OpenPara-Setup-<version>.exe. No administrator rights are needed.
  2. Start OpenPara from the Start menu.
  3. Stay up to date with Help > Check for updates. New versions install for you, and your settings and material library are kept.

Linux and macOS, or from source

OpenPara is written in Python. Install the packages and run it:

git clone https://github.com/Bubbletoppoet47/OpenPara.git
cd OpenPara
pip install -r requirements.txt
python gpd_app.py
Tested on Windows. The Windows installer is the tested way to run OpenPara. Running from source on Linux or macOS should work but has had less testing.
