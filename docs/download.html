Windows installer

Installs for your user only (no administrator rights), with its own Python and every package it needs. Adds a Start-menu entry.

Download the installer
Latest version: see the releases page.

Install

  1. Download OpenPara-Setup-<version>.exe and run it.
  2. Start OpenPara from the Start menu.
  3. Later, Help > Check for updates installs new versions for you. Your settings and material library are kept.

Linux and macOS, or from source

OpenPara is Python. Install the packages and run it:

git clone https://github.com/Bubbletoppoet47/OpenPara.git
cd OpenPara
pip install -r requirements.txt
python gpd_app.py
The Windows installer is the tested way to run it. Running from source on Linux or macOS should work but has had less testing.
