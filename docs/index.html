Free parametric CAD for everyone from hobbyists to engineers

OpenPara is an open-source parametric modeller: sketch with constraints, build parts and assemblies, make gears from a few numbers, run simulations and render the result, all in one program.

Download for Windows See what it does
Free and open source (GPL-3.0). Windows installer; Linux and macOS can run it from source.

What you can do with it

One program, from a first sketch to a finished, simulated and rendered design.

Model

Parametric parts

Constrained sketches, extrude, cut, revolve, sweep, loft, fillet and chamfer. Change a dimension or a named variable and the part rebuilds.

Assemble

Assemblies

Mates, sub-assemblies and their own variables. Positions and spacing can be formulas.

Generate

Part Generator

True involute spur, helical, herringbone and internal ring gears. Size a gear train or a planetary set from centre distances or ratios.

Analyse

Simulation

1D beam and frame analysis, 2D finite-element analysis and 2D flow, with results you can slice and inspect.

Show

Photorealistic renderer

Sun and sky from a date, time and place, lights, cameras, still pictures and MP4 videos.
