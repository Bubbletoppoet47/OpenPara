# System dynamics (planned)

Mechanical system dynamics: lumped masses, springs, dampers, rotating inertias, gears and force / torque sources in a diagram; time response,
natural frequencies and mode shapes, frequency response. Shares its network solver with `addons/circuits`; a motor can later be modelled as
an electrical and a mechanical system together. Rigid-body motion of whole assemblies (mates, contact) comes after the lumped version.
