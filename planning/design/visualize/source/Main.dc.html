What this board decides
One wire in. A Visualize node takes one input. For a combined result, wire the analyses into Coupled Physics and wire its Results.
Two modes, chosen by the input. A part, geometry or assembly opens the render studio: looks, lights, floor, environment, cameras. A simulation result opens the result view: a vacuum look (no lights, no environment) and a rotation.
Its own copy. The node keeps a copy of what it was given inside the .opara. Opening the project never changes it. Run the simulation again, then Update the node.
One field. From a simulation it takes the field that is on screen in the simulation window when it is wired. Another field: change it there, then Update.
Export lives here. The simulation windows keep their basic view and Animate preview. Export animation and Save image move to this node (board 5).
